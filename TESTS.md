# Tests

The audit engine must be tested as deterministic business logic. Unit tests should not call Firebase, Resend, Anthropic, or browser APIs. All tests live under `tests/audit-engine`.

## Test File 1: `tests/audit-engine/plan-overkill.test.ts`

Purpose: verify that premature team plans are treated as retail traps.

Cases:

| Case | Input | Expected |
| --- | --- | --- |
| Claude Team with 2 seats | `$125/month`, `2 seats`, `teamSize=2` | Recommend Claude Pro and calculate `$85` monthly savings. |
| Cursor Business with 2 seats | `$80/month`, `2 seats`, `teamSize=2` | Recommend Cursor Pro and calculate `$40` monthly savings. |
| v0 Team with 2 seats | `$60/month`, `2 seats`, `teamSize=2` | Recommend v0 Premium and calculate `$20` monthly savings. |

Implemented starter assertion:

```ts
expect(audit.totalMonthlySavings).toBe(85);
expect(audit.findings[0]?.recommendation).toContain("Pro");
```

## Test File 2: `tests/audit-engine/alternatives-by-use-case.test.ts`

Purpose: verify that cheaper alternatives are mapped by use case and not randomly generated by AI.

Cases:

| Use case | Expected alternatives |
| --- | --- |
| coding | GitHub Copilot Individual, Cursor Pro, v0 Premium |
| writing | ChatGPT Plus, Claude Pro |
| data | OpenAI API mini-tier, Gemini API |
| research | Claude Pro, Gemini Pro |
| mixed | ChatGPT Plus, Claude Pro |

Implemented starter assertion:

```ts
expect(audit.alternatives.map((alternative) => alternative.tool)).toContain("GitHub Copilot");
expect(audit.alternatives.map((alternative) => alternative.tool)).toContain("Cursor");
```

## Test File 3: `tests/audit-engine/credex-thresholds.test.ts`

Purpose: verify the strict CTA thresholds required by the assignment.

Cases:

| Savings | Expected CTA |
| ---: | --- |
| `$501+` | `credex_consultation` |
| `$100-$500` | `benchmark_report` |
| `<$100` | `optimization_gate` |

Implemented starter assertion:

```ts
expect(audit.totalMonthlySavings).toBeGreaterThan(500);
expect(audit.ctaState).toBe("credex_consultation");
```

## Test File 4: `tests/audit-engine/api-vs-seat-spend.test.ts`

Purpose: verify that direct API spend is treated as usage spend, not as seat spend.

Cases:

| Input | Expected |
| --- | --- |
| Anthropic API direct, `$700/month`, `2 seats` | Recommend budget cap and calculate savings against the cap. |
| OpenAI API direct, `$950/month`, `3 seats` | Trigger Credex consultation when savings exceed `$500`. |
| Gemini API, small invoice | No forced seat-plan downgrade. |

Implemented starter assertion:

```ts
expect(audit.findings[0]?.recommendation).toContain("budget cap");
expect(audit.findings[0]?.monthlySavings).toBe(550);
```

## Test File 5: `tests/audit-engine/spending-well.test.ts`

Purpose: verify that the app is honest when there is no meaningful savings opportunity.

Cases:

| Input | Expected |
| --- | --- |
| Cursor Pro, `$20/month`, `1 seat` | `$0` savings and `optimization_gate`. |
| GitHub Copilot Individual, retail spend | No Credex consultation CTA. |
| ChatGPT Plus, single user retail spend | No downgrade finding. |

Implemented starter assertion:

```ts
expect(audit.totalMonthlySavings).toBe(0);
expect(audit.ctaState).toBe("optimization_gate");
expect(audit.thresholdMessage).toContain("spending well");
```
